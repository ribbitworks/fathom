# Change history

Change history lists every change saved to the plan, people and configuration, newest first. Each entry says who made the change and what changed, with the old and new values.

## Main Tasks

### Find a Change

Type in **Search change history**, such as a person's name, a value or who made the change.

### Read an Entry

- Each entry has a sentence for each record the save changed, such as **changed the list Sites: Name from Sites to Locations**.
- When a save changed many records, a button such as **Show 3 more** lists the rest, and **Show all** lists every name in a line.
- Select **Show more** at the end of the page for older entries, also while searching.

## Marks and Terms

- **A yellow dot** before an entry means it deserves a second look.
- An entry lists only changes to data the account can see.
- Undoing a change adds a new entry that puts the old values back. Nothing is ever taken out of the history.

## Where Changes Go

Change history only reads, and changes nothing. Drafts and what happens to them are in [Drafts](drafts.md).
