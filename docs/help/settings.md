# Settings

Settings holds Fathom's settings for the whole organization: its time zone, and the rules for passwords. Each has its own panel.

## Main Tasks

### Change the Time Zone

1. Type part of the time zone's name in **Time zone**, such as `Vancouver`, and choose it.
1. Check the day and time under it.
1. Select **Save**.

### Set the Rules for Passwords

1. In the **Passwords** panel, under **Password requirements**, set the **Minimum length**, and tick what each password **Must have**.
1. Under **Generated passwords**, set the **Length**, what they **Use**, and whether they **Leave out characters that look alike**.
1. Select **Save**.

## Marks and Terms

- **Time zone** decides which day is today, for everyone: the date a change takes effect when none is given, and who still works here. Times shown on screen still follow each person's own settings.
- **Password requirements** are the rules for passwords people choose. A tighter rule applies the next time each person changes their password.
- **Generated passwords** are the passwords Fathom makes, such as for a new account. A red box says why when they would break the requirements, and **Save** stays off until that's fixed.
- Common or easily guessed passwords are always refused, whatever the settings say.

## Where Changes Go

Settings change at once, for everyone, with no draft. Each change is recorded in the access history.
