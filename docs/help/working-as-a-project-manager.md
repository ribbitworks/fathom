# Working as a Project Manager

A Project Manager sees projects through to delivery: their milestones, the features they need, and the people and teams working on them. Project Managers see people with their Personal and Confidential data and the hiring plan, and approve drafts of the plan, features and releases, people and planned hires, feature teams, lists, and the planning settings.

## Keep a Project on Track

1. On **Projects**, open the project's details, as [Projects](projects.md#see-a-records-details) sets out.
1. Add or change its milestones, as [Projects](projects.md#add-a-milestone-to-a-project) sets out. **Next delivery** follows from them.
1. Read its **Scope history** for each feature added or removed, and when, as [Projects](projects.md#see-how-a-projects-or-proposals-scope-changed) sets out.
1. Select **Show features** in the project's **⋯** menu to see where each feature it needs stands, as [Projects](projects.md#go-from-a-project-to-its-milestones-or-features) sets out.
1. Select **Publish** in the top bar.

## See Who Works on What

1. Select the **Feature assignments** page to see who is on which feature team each month, as [Feature assignments](feature-assignments.md#read-the-table) sets out.
1. Select the **Capacity** page, and choose **People**, to see what each person works on, as [Capacity](capacity.md#read-who-works-on-what) sets out.
1. Group by **Feature team** to see each team's people together, as [Capacity](capacity.md#group-the-rows) sets out.

## Approve Others' Drafts

1. Select the **Drafts** page.
1. Approve or reject the drafts waiting, as [Drafts page](drafts-page.md#approve-drafts) sets out.

A Project Manager's own drafts need another approver.
