# Saved views

A view is how you've set up a table: its search, filters, sort, metrics, **Group by**, with its **Then by**, the **Draft** menu's choice, and its columns' order, hidden columns, widths, frozen columns, and units and decimal places. On **Releases**, it also keeps whether **Show retired** is on. On **Drafts**, it also keeps its tab. On **Features**, it also keeps the board's schedule and what its cards show. The table and the board share one view. Switching between them doesn't change it. You can save a view under a name, and apply it again later. You can save views on the **People**, **Features**, **Projects**, **Releases**, **Org chart**, **Feature assignments**, **Accounts** and **Drafts** pages, and in **Capacity**'s **People** mode. Each tab of **Projects** has views of its own. **Feature assignments** and **Capacity** each have their own views too. On the **Org chart**, a view keeps how the chart is drawn instead, as [Org chart](org-chart.md#save-a-view-of-the-chart) says.

You save and apply views from the **Views** menu: the last button after the search box, or, on the **Org chart**, the last of the buttons on the left above the chart. It shows once there's a view to save or apply, or a hidden column to show.

## What to Know First

- **Personal views:** a view you save is yours alone, unless you share it. Your own views are under **My views**.
- **Shared views:** a shared view is seen by everyone who can open the page. They're under **Shared views**. Someone who can't see a column the view uses doesn't see the view. On **Feature assignments** and **Capacity**, a view grouped by **Manager** is seen only by roles that see Confidential data.
- **Who can share:** you can share a view you saved yourself, if your role changes configuration, or, on **Accounts**, if it manages accounts. Only a view's maker, or a role that can share views on the page, can change, rename or delete a shared view.

## Main Tasks

### Save a View

1. Set up the table the way you want it.
1. Select **Views**.
1. Select **Save view…**. While a view is applied, it reads **Save as new view…**, and the view applied stays as it was.
1. Type the view's **Name**.
1. Check what the view keeps, under **Includes**.
1. To share it, tick **Share with everyone who sees this page**.
1. Select **Save view**.

You're done when the **Views** button shows the view's name.

### Apply a View

1. Select **Views**.
1. Select the view's name.

You're done when the **Views** button shows the view's name, with a tick beside it in the menu.

### Change a View

1. Apply the view.
1. Change the table.
1. Select **Views**.
1. Select **Update view**. It shows once the table has changed.

To rename the view, select **Rename…** in the same menu. To delete it, select **Delete view**.

You're done when the dot after the button's name is gone.

### Share a View or Stop Sharing It

1. Apply a view you saved.
1. Select **Views**.
1. Select **Share current view** to share it, or **Stop sharing current view** to make it personal again.

You're done when the view moves to **Shared views**, or back to **My views**.

### Go Back to the Table's Own View

1. Select **Views**.
1. Select **Clear view**.

**Clear all**, above the table, does the same, but leaves the **Metrics** panel open.

### Tidy a View You Can No Longer Use

Your role might lose sight of a column one of your views uses. The view then stays under **My views**, dimmed, with a line saying what it uses, such as **Uses Site, which this role can't see.** You can't apply it, but you can rename or delete it.

To rename it:

1. Select **Views**.
1. Select the dimmed view.
1. Select **Rename…**.
1. Type the view's new **Name**.
1. Select **Rename**.

To delete it:

1. Select **Views**.
1. Select the dimmed view.
1. Select **Delete…**.
1. Select **Delete**. This can't be undone.

You're done when the view has its new name, or is gone from the menu. If your role sees the column again, the view works again as it was.

### Hide a Column and Show It Again

A hidden column leaves the table, but still counts. Its filter and sort still apply, and **Metrics** can still break down by it. An export leaves it out. You can hide any column except the one naming each row, such as **Name** on **People**.

1. Open the menu on the column's heading.
1. Select **Hide column**.

To show it again:

1. Select **Views**.
1. Under **Hidden**, select the column's name.

Some columns start hidden, such as **Key**. They're under **Hidden** from the start, and you show them the same way.

With two or more columns hidden, **Show all columns** under **Hidden** shows them all.

You're done when the column is back in its place.

### Undo One Part of a View

In the **Views** menu, under **Sort**, each level of the sort is named, and then any frozen columns, moved columns, hidden columns, set widths and units. Select one to undo just that part.

## Marks and Terms

- **A tick** in the menu marks the view applied.
- **A dot** after the button's name means the table has changed since you applied the view. With no view applied, it means there's something to save.

## Where Changes Go

A saved view isn't a draft. It's saved straight away, without approval. Sharing a view, stopping sharing it and deleting it each offer **Undo** for a few seconds. Renaming or deleting a view you can no longer use can't be undone.
